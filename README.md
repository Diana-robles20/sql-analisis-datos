# **SQL Data Analysis Repository**

This repository showcases SQL projects focused on analyzing relational data and extracting meaningful insights. It is organized into two main sections based on the level of complexity and analytical approach.

---

## **Querying**

This section focuses on foundational SQL techniques used to explore and analyze data within individual tables.

### **Topics included:**

- SELECT statements  
- Filtering with WHERE  
- Sorting with ORDER BY  
- Aggregations (SUM, AVG, COUNT)  
- GROUP BY and HAVING  
- Top N analysis  

This section demonstrates the ability to efficiently extract, clean, and summarize data.

---

## **Relating**

This section highlights more advanced SQL techniques used to work with multiple tables and uncover deeper insights.

### **Topics included:**

- JOIN operations 
- Nested subqueries 
- Relationship analysis between entities   

This section demonstrates the ability to analyze relational databases and solve complex data problems.

---

## **Objective**

The goal of this repository is to demonstrate strong SQL proficiency for data analysis, progressing from foundational querying to advanced relational problem-solving.
